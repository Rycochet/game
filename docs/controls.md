# Controls

Everything can be done with a mouse or by touch, and on touch screens a tap is a click.

## Moving

| Action | Keyboard and mouse | Touch |
| ------ | ------------------ | ----- |
| Take steps | Arrow keys or W, A, S, D | |
| Travel somewhere | Click the place | Tap the place |
| Enter a place, take stairs, leave a site | Click it, and walk there | Tap it |

## Camera

| Action | Keyboard and mouse | Touch |
| ------ | ------------------ | ----- |
| Turn and tilt | Drag with the right button | Twist two fingers to turn, move both up or down to tilt |
| Zoom | Mouse wheel | Pinch |
| Back to the starting view | Home | Reset View in the [debug menu](debug-menu) |

## Maps and menus

| Action | Keyboard and mouse | Touch |
| ------ | ------------------ | ----- |
| Open or close the full map | M, or click the minimap | Tap the minimap |
| Move and zoom the full map | Drag, mouse wheel | Drag, pinch |
| Open the system menu | Esc, or click the gear in the top-right corner | Tap the gear |
| Close what is on top | Esc, or click outside it | Tap outside it |
| Open the [debug menu](debug-menu) | Backtick (`` ` ``), or click the warning button at the top left | Tap the warning button |

Esc goes to whatever is on top first: a text box, a dropdown, the debug menu or the full map, and only then the system menu.

## While the system menu is open

The menu takes all the keys, the wheel and the gestures, so nothing behind it reacts. In single player the game is paused too. On a networked server it isn't, and a journey you clicked on carries on: see [Pausing](client#pausing).
