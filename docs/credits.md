# Credits and licence

Who made Hall of Worlds, and what it is made with. The game's own Credits, in the system menu, are grouped the same way.

Artwork, fonts and models by other people keep their own licences. The [attribution file](https://github.com/ReigningCoo/hall-of-worlds/blob/master/crates/client/assets/ATTRIBUTION.md) has the sources and any changes made.

## Made by

- **Created by:** Ryc O'Chet.
- **Code and placeholder 3D images:** Claude Code (Opus 5.5). This game would not have been possible without it.

## Art

- **Monster and terrain tiles, and the AngbandTk tiles:** David E. Gervais, from the [D. Gervais tiles library](http://pousse.rapiere.free.fr/tome/) (CC BY 3.0).
- **Icons:** Lorc, Delapouite and the other contributors to [game-icons.net](https://game-icons.net) (CC BY 3.0); the attribution file names them all.

## Fonts

- **Cinzel Decorative:** Natanael Gama (SIL Open Font License 1.1).
- **Lexend:** Bonnie Shaver-Troup, Thomas Jockin, Santiago Orozco, Héctor Gómez and Superunion (SIL Open Font License 1.1).
- **Noto Emoji:** Google (SIL Open Font License 1.1).

## Models and shapes

- **The shapes of animals' bodies and heads:** measured from animal models by JALdMIC (CC BY), made for [MakeHuman](http://www.makehumancommunity.org), whose own model of a person (CC0) they reshape. The game holds only the measurements, not the models.
- **Some creatures (the drider):** from the System Reference Document 5.1 ("SRD 5.1") by Wizards of the Coast LLC, available at <https://dnd.wizards.com/resources/systems-reference-document>. The SRD 5.1 is licensed under the [Creative Commons Attribution 4.0 International License](https://creativecommons.org/licenses/by/4.0/legalcode).

## Software

- **Built with:** [Bevy](https://bevy.org/) and the many other open source libraries it and the game use, which keep their own licences.
