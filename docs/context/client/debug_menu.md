# client: debug_menu

The debug menu: backtick or the warning button top left opens a full-screen layer (`widgets`, 90% of the window) listing actions, filtered by typing, chosen by click, tap, arrow keys and Return. Entries with a submenu end in "..." (`DebugAction::label`, by `has_submenu`), and their plain name is the submenu's title (owner's convention). Replaces the old demo keys. Works in native and web builds.

## Public API

- `DebugMenuPlugin`.
- `DebugAction` (message): do this, as if chosen. Used by `dev_tools` (`HOW_DEBUG_PANEL`, and the debug API's `client.debug_action`, which finds it with `DebugAction::named`; `DebugAction::names` lists them).
- `DebugMenu` (resource): `open`, `filter`; `open_with` (native, for `HOW_DEBUG_MENU`).
- `AutoWalk(bool)` (resource): the player walks east one step per frame on the world map. `TemperatureCycle` (resource): `Off`, `Cooling`, `Warming`; the snow line falls to 0 and back through the server (`DevSnowLine`), and it turns itself off at the end.

## Notes

- Owner's design, after RimWorld's: choosing an entry closes the menu; a toggle shows its new state for `TOGGLE_SECONDS` (0.4, owner: just past the press's ripple) first. Disabled entries stay visible and do nothing. Columns fill top to bottom, then overflow into the next.
- Claude's choices: Return with nothing highlighted takes the first entry that can be used; arrow keys can highlight disabled entries; Esc, its close button and a click outside it close it too; backtick does nothing over the full map, as the menu would be the bigger of the two (owner's rule: a layer above is smaller); turning Cycle Temperature off puts the snow line straight back; only one of Teleport and Change Cell Mode can be on. Reset View is here as tablets have no Home key (Home still works).
- While open it takes all input: `take_input` clears keys, wheel and gestures, and its layer stops presses, so nothing behind it reacts.
- With the filter box focused in a browser, the game's keys see nothing, so its Return and Escape come through `widgets::SoftKeyPressed`, and arrow keys on an attached keyboard don't work until tapping elsewhere is added.
- Panels stay open with greyed buttons where they can't act. Stairs, fields and herbs changes are only what is drawn; the next level goes back to its own, except herbs (`HerbGrowthShift` stays).
- Suns and Moons (`bodies.rs`): a row per sun, a gap, a row per moon: a swatch of its colour and a slider along its kind's colours (`shared::celestial::colour_along`), and for suns a slider for intensity (`MOST_INTENSITY`; above about 1.15 on flat ground `world_map`'s cap holds it). Only this client's drawing, until the world is joined again. A generated body can be paler than anything on its slider: the mark goes to the nearest, and the swatch shows it exactly until it is moved.
- World Time and Suns and Moons toggle their panels, and their entries have checkboxes saying whether they are open (`OpenPanels::toggle`, `forget_closed` for close buttons).
- World Time's panel (owner's design) asks the server to move the world's clock (`DevSetWorldClock`), on either map, for everyone in that world: small buttons -1d to -1m, a box, +1m to +1d, all one height and touching. The box shows `Day N HH:MM` (days from 1) and follows the clock unless it has the keyboard; giving the keyboard up by Return or clicking away sets that time (a bare `HH:MM` is on the day shown), Esc puts the real time back and sends nothing (the box takes the key, so the panel stays). What can't be read keeps an error edge until edited or a step is pressed. It stops at the world's beginning. A second row (`panels/world_rate.rs`) sets how fast the world's time runs, x1/4 to x600, the rate in use `Selected`.
- Change Creature: a moveable panel with a button per kind of creature (`DevSetCreature`).
- Give Item: a moveable panel with tabs for the size it is made for and whether it is magical, and a button per kind of item (`DevGiveItem`); each press puts a new one in the inventory if there is room, which the Character panel shows (I, or the bag button).
- Item Pictures: a moveable panel with a dropdown of pages (`PicturePage`: Bodies, Hands, Shoulders, Arms, Torso, Waist, Legs, Feet, Footwear, Head, Neck, Sets, Weapons, Gems, Rings; the last chosen kept by name in `common::Preferences`, Gems if none or unknown), tabs for quality, and a scrolling grid that `fill_pictures` rebuilds with only that page's rows, so only those are drawn (the cut names head the Gems page only). The pages between them show a bare body of each kind on two legs and a row of the first bipeds to come (`shared::body::FIRST_BIPEDS`), a sample of gauntlets, demi-gauntlets and padded gloves as rolled (one row with a kobold's hands) and plate gauntlets in each style, a sample of each kind of shoulder piece as rolled and plate pauldrons in each style, a sample of weapons of each family, every gem in every cut and a sample of rings as the server would roll them (`item_art`, `give_form`); pressing one shows it large. It only draws here, so it needs no server. A new kind with models gets its own page.
- Truesight (`common::Truesight`, `DevTruesight`): the server sends items' secrets and secret doors, without them being found out; `remind_of_god_mode` tells a new connection too, `trade` asks again for what is open, and `ui` shows eyes. Later, anything else hidden should go by the same flag, on both sides. Give Item's tabs set `magical` and `favour`, as secret as on anything found.
- God Mode (`common::GodMode`, `DevGodMode`): the server has the rules (see `server`); `remind_of_god_mode` tells a new connection, `player` stops treating enemies as in the way, and `ui` shows a ghost. Further powers should go by the same flag, on both sides, rather than new entries.
- Kill Mob (`common::KillMob`, owner's design): only clicks change; movement doesn't, and it isn't saved. `entities` makes mobs clickable and sends `DevKillMob`, and `ui` shows a skull beside the ghost.
- Change Cell Mode, Change Creature, Cycle Temperature, Forget Map, Forget Map (Server), God Mode, Kill Mob, Reveal Map, Teleport Mode, Teleport to Hall of Worlds, Teleport to POI Showcase, Teleport to Start and Truesight need the server's dev tools (`common::ServerDevTools`, from `Welcome`), and are disabled where it refuses them. The embedded server always allows them; a standalone one with `HOW_DEBUG_TOOLS=true`.
- Reveal Map and Forget Map are answered by the server sending the level again as if arriving where the player stands (`EnterLevel`), or for forgetting the world map `ForgetWorldMap` and the chunks in sight. Both are disabled in towns, which arrive whole. Forget Map on the world map also forgets what the character remembers of every site. Forget Map (Server) does the same and has the server forget the site or, on the world map, every site (`DevForgetMapOnServer`), so they are made anew with the current generators; it works in towns too.
- Generate POI... (owner's design): a second layer (75%) with the same grid and search, listing every kind alphabetically. Choosing one closes both layers and opens a moveable panel (`panels::GenerateKind`, `GenerateForm`): the kind as words, ruin 0 to 5 (grey for kinds that can't be), the seed box with a new seed button (a drawn round arrow, as the font has none), and Generate (`DevGenerateSite`). Claude's choices: the panel stays open to try more seeds, and choosing another kind replaces it; Esc, the close button or a click outside goes back to the first layer with its filter kept; backtick closes everything; a new seed has up to 9 digits, though any `u64` can be typed. Where columns don't fit, the grid shows a window of them, moved by the wheel, by following the arrow keys, or by the `<` and `>` buttons in the title row, which show only then.
