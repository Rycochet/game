# Difficulty

Each character plays on one of four difficulties. A server may allow only some of them. If yours stops allowing the one you play on, you are moved to the nearest it does allow (the easier one if two are as near).

| Difficulty | Harm you take | Health and Mana refill | When you die |
| ---------- | ------------- | ---------------------- | ------------ |
| Easy | A fifth less | Twice as fast | Nothing is lost. |
| Normal | As usual | As usual | As the game is meant to be played. |
| Hard | A fifth more | As usual | Nothing extra is lost yet. |
| Ironman | A fifth more | As usual | Nothing extra is lost yet. |

Choosing a difficulty, and what Hard and Ironman cost you when you die, are coming soon. Ironman will only be chosen when making a character, and can never be changed to or from.

## For server hosts

A server allows every difficulty unless `HOW_DIFFICULTIES` lists the ones it allows: see [Environment variables](environment-variables).
